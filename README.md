# 🛒 Amazon Product Price Analysis

A **Data Mining** project developed using **Python**** to analyze Amazon product data. The application processes product information and generates interactive visualizations that help users understand pricing trends, discounts, customer ratings, and category-wise product analysis.

## 📌 Project Overview

The **Amazon Product Price Analysis** platform applies **Data Mining** techniques to extract meaningful insights from Amazon product datasets. It performs data preprocessing, exploratory data analysis (EDA), and visualization to transform raw product data into valuable business information.

The interactive dashboard enables users to explore pricing patterns, discount distributions, customer ratings, and product categories through dynamic charts and graphs.

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/anai-rgb/Amazon-Product-Price-Analysis.git
```

2. Navigate to the project directory

```bash
cd Amazon-Product-Price-Analysis
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application

```bash
streamlit run app.py
```
